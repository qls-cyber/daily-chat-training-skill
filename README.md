# 日常社交对话训练 Skill（social-conversation-trainer）

一个通过角色扮演练习日常社交对话的 Codex Skill。Codex 在对话中扮演场景角色与你对话，同时以【教练提示】给出简短、可执行的改进建议。

## 1. 项目解决什么问题

很多人在真实社交场景中不知道如何开口，或措辞生硬、表达含糊、回应过短。这类能力缺少低成本、可重复的练习方式。

本项目把社交练习变成一场结构化的对话训练：在一个没有评判压力的环境里，用户向 Codex 扮演的角色说话，每轮立刻获得针对性反馈，练习结束后还能得到按维度拆解的总结点评。目标是让改进落到具体场景和具体句子上，避免泛泛而谈。

## 2. 主要功能

- 双重身份：同一段对话中，Codex 既以场景角色回应 1-2 句，又以【教练提示】给出不超过 20 字的改进建议
- 关系类型：同学、老师、陌生人、长辈
- 难度分级：入门、日常、高难度。高难度下角色会适度冷淡、反问或制造阻力，倒逼用户调整表达
- 引导规则：发言不足 15 字时角色追加追问；措辞生硬时教练给出更自然的替代说法
- 开场示范：练习开始时展示一段 2 轮示范对话，换场景后不再重复展示，示范不计入练习轮次
- 自动总结：默认完成 4 轮计轮发言后给出总结点评，重试不增加轮数
- 总结点评：包含 1 处亮点和 2-3 条问题，每条带改进建议和对比示范
- 控制指令：`重来` 重试当前轮，`换场景` 切换新场景，`结束` 提前总结
- 场景示例库：内置 12 个常见场景，可按用户设定的关系与难度改编
- 纯指令型设计，无脚本、无运行时依赖

## 3. 安装方法

前置条件：已安装 Codex（桌面版或 CLI）。

Codex 会自动发现 skills 目录下的 `SKILL.md`。选择以下任一方式安装：

### 方式一：安装为个人 Skill（推荐）

将 `social-conversation-trainer` 目录复制到个人 skills 目录 `$CODEX_HOME/skills`（未设置 `CODEX_HOME` 时默认 `~/.codex/skills`，Windows 为 `%USERPROFILE%\.codex\skills`）。

macOS / Linux：

```bash
mkdir -p ~/.codex/skills
cp -r social-conversation-trainer ~/.codex/skills/
```

Windows（PowerShell）：

```powershell
New-Item -ItemType Directory -Force $env:USERPROFILE\.codex\skills
Copy-Item -Recurse .\social-conversation-trainer $env:USERPROFILE\.codex\skills\
```

安装后新建一个 Codex 会话即可使用。

### 方式二：随项目分发

将 `social-conversation-trainer` 放入仓库根目录的 `.codex/skills/` 下，团队内共享项目时即可被 Codex 发现。

### 方式三：免安装直接引用

在 Codex 对话中引用本仓库里的 `social-conversation-trainer/SKILL.md` 路径即可使用，无需复制。

## 4. 使用方法

在 Codex 对话中输入一个社交场景即可触发，关键词、短句或完整情境均可，可选标注关系类型和难度：

- 借笔记
- 请老师课后答疑，老师，日常
- 和陌生人在咖啡店聊天，高难度

未标注关系类型时默认 同学，未标注难度时默认 日常，开场会明确告知默认值。

练习流程：

1. Codex 展示 2 轮示范对话，然后提示开始练习
2. 每轮你发言后，Codex 以角色身份回应 1-2 句，并给出不超过 20 字的教练提示
3. 完成 4 轮计轮发言后自动总结；练习中可随时使用控制指令

控制指令：

| 指令 | 作用 |
| --- | --- |
| 重来 | 重试当前轮，不增加轮数 |
| 换场景 | 切换到新场景，轮数重新开始 |
| 结束 | 立即进入总结点评 |

## 5. 输入输出示例

输入（触发场景）：

> 我要找同学借笔记，日常

输出（开场，节选）：

> 设定：向同学借课堂笔记，关系 同学，难度 日常。先看一段 2 轮示范……下面开始练习，请直接对我说第一句。

输入（练习第 1 轮）：

> 同学，可以借一下你的笔记吗，我平时没做

输出：

> 同学：可以啊，你要补哪部分？我看看借你哪几页合适。
>
> 【教练提示】把“没做”换成“没记全”，更自然。

输入（结束）：

> 结束

输出（总结节选）：

> 做得好的 1 处：你用了“同学”称呼和商量式语气，礼貌不生硬。
>
> 待改进 1（措辞选择）：“我平时没做”偏模糊，建议换成“我上课经常走神，没记全”。
>
> 下一步：继续练同一场景 / 换场景 / 结束。

## 开发与验证

- 无脚本依赖，改动 SKILL.md 即可调整行为
- 已通过官方 `quick_validate.py` 校验。校验脚本依赖 PyYAML，Windows 控制台运行建议设置 `PYTHONUTF8=1` 以避免默认 GBK 编码读取 UTF-8 文件时报错
